A race has not been deployed. Observed median first-valid time in parallel trials: 3.09 s. Returning early, cancellation, late disagreement, and loser billing require a separate implementation and evaluation.
The main gap is intent validation. In the historical baseline, both modes accepted all three missing-thickness trials and all three explicitly undecided-quantity trials. Baseline parsing also silently reversed the impossible ring dimensions once. Parallel checking reduced wrong acceptances from 9 to 6, while blocking three complete orders instead of one. All 60 baseline provider calls succeeded at the API level; provider failover itself was not exercised.

Selecting the first schema-valid candidate from the recorded parallel responses would have yielded 50/60 correct outcomes and 10 wrong acceptances. This is an observational selection analysis, not an executed race or an estimate of cancellation costs.

ADR 006 / Provisional routing decision

Published baseline produced 50/60 correct outcomes at a 3.23-second median; parallel agreement produced 51/60 at 18.73 seconds. Historical decision: keep primary-first routing provisionally and prioritize explicit missing-input and contradiction checks before changing the default provider policy. The parallel agreement policy remains experimental; this benchmark does not justify enabling an automatic race. Parallel agreement caught some errors, so retain it as a candidate review mode; its measured delay and blocked complete orders count against making it mandatory.

02 / How the comparison works

01

Fix expectations before the calls

15 complete orders and five incomplete, undecided, conflicting or impossible instructions. Expected outcomes are derived from explicit synthetic instructions; no model judges the answers.

02

Use the production extraction prompt

Same schema, temperature 0.1 and 2,048-token limit. Run each prompt three times per policy, in a fixed shuffled order. Maximum two simultaneous trials / four provider calls.

03

Compare manufacturing requirements

Grade, thickness, kerf, quantities, dimensions, grain restrictions and DXF binding matter. Generated IDs do not. Equivalent unlocked rotations and grouped identical items are normalized.

04

Preserve the application

No SAM requests, nesting, machine output or inventory transactions. Backend Python, real configuration and warehouse database hashes are checked before and after. Verified unchanged after the run.

Where the DXFs come from

Generated locally with the existing exporter, then checked for exact polygon equality using the actual loader. Closed straight polylines, millimeter units, no downloaded vendor files. Paths are supplied as upload context; this experiment does not exercise HTTP upload.

03 / Architecture decision log

ADR 001

Models interpret; geometry verifies

Models supply segmentation and order interpretation. Local geometry determines placement; a deterministic compiler emits a bounded toolpath. Model confidence is not a substitute for checking the final program.

Tradeoff: a valid toolpath can still describe a misunderstood order. Explicit intent checks and user review remain necessary.

ADR 002

Verify the complete batch, then commit once

Every used sheet must pass final-program verification before one SQLite transaction changes inventory. Stale geometry, material, thickness or provenance rejects the update; partial orders cannot commit.

Boundary: inventory records predicted post-cut stock. The API does not execute a machine or confirm a physical cut.

ADR 003

Real SAM, explicit local demonstrations

Meta SAM 3.1 provides the segmentation mask. Local thresholding is a separately selected demonstration mode with persistent provenance. Lighting normalization remains opt-in.

Two cardboard specimens and eight captures have been evaluated: five usable contours and three blocked captures. Physical error and reflective-metal qualification remain limits; see the measured report.

ADR 004

Material grades remain distinct

SS304 and SS316, or AL6061 and AL5052, cannot silently substitute for each other. Explicit recognized prompt grades are checked against the interpreted order.

Tradeoff: conservative identities avoid substitutions but do not provide a comprehensive alloy-equivalence database.

ADR 005

Bounded CAD and controller contracts

DXF import supports one planar boundary and disjoint holes using closed straight polylines or closed planar splines with declared-unit conversion. Prepared controller emitters target bounded GRBL 1.1 and LinuxCNC laser configurations, with optional checked arc lead-ins. Unsupported geometry and commands fail clearly.

Closed straight LWPOLYLINE and closed planar SPLINE loops are supported. Declared mm/cm/m/inch units convert to mm; unitless means mm. Splines use a disclosed 0.05 mm chord tolerance. Native circles/arcs, bulges, blocks, open/3D contours and invalid holes remain unsupported. No arbitrary controller, dimensional kerf compensation or machine qualification is claimed.

ADR 006

Choose provider policy from observed behavior

Removing unused blackboard functions simplified the running path but did not demonstrate that parallel execution was worse. This experiment records latency, correct outcomes, wrong acceptance, blocked orders and token usage.

Boundary: two deployments of the same model family can agree on the same mistake. Agreement does not prove intent or physical safety.

ADR 007

Keep demo stock explicit

Startup does not seed inventory. Synthetic and local-threshold stock retain source provenance and require an explicit opt-in during order execution. A separate demo database can be selected.

Reason: demonstration material must not silently become real warehouse availability.

ADR 008

Measure timings; leave unsupported savings unset

Stage durations, quantities, usable area and utilization are measured. Money and carbon savings stay unset until equivalent-production baselines, prices and lifecycle assumptions exist.

Reason: packing utilization alone does not establish financial or environmental savings.

ADR 009

Keep the backend easy to trace

HTTP routes delegate manufacturing orchestration to one pipeline module. Shared schemas describe requests; serialization converts geometry and results to API data. The nester uses NFP contact placement and seeded parallel simulated annealing.

Tradeoff: clear local responsibilities and compatibility aliases support development, but do not provide global nesting optimality, distributed scheduling or a production job system.

ADR 010

Review geometry and retain the exact verified plan

Photo analysis stays outside available inventory until a worker accepts its outline and holes. Saved plan IDs bind completion to the exact verified program and stock snapshot; stale stock blocks updates.

Read the review and recovery decision (Markdown).

Physical test

Compare predictions with separately measured specimens

Two cardboard specimens, eight captures: five usable SAM contours with correct topology and three blocked captures. Exterior error reached 7.32 mm. The corrected 80 mm rectangle-to-circle gap measured 80.54 and 81.36 mm. References were corrected after results; no uniform accuracy certification is claimed.

05 / What the evidence does not establish

  • Identical production extraction prompt captured without a network call.
  • Two concurrent trials: results reflect light benchmark load, not isolated single-request latency.
  • Parallel agreement deliberately waits for both providers. No production race or cancellation is tested.
  • First-valid time is observational and excludes production race coordination/cancellation.
  • Safe rejection is a fail-closed outcome, not proof that a useful clarification question was generated.
  • Expected answers are agent-authored from explicit synthetic instructions; no user/domain-expert signoff.
  • No SAM, nesting, G-code generation, real inventory or file-upload HTTP endpoint is exercised.
  • Cost is an estimate from reported tokens and public list prices, not grant-account billing.

The two-request connectivity pilot is excluded from the 120-trial totals. Public model pricing was checked on 29 October 2026: $1.25 input, $0.15 cached input, $4.25 output per million tokens on each host. Estimates use reported usage, not account invoices or grant deductions.

ADR 011

Search in the sheet frame as well as the station frame

A rotated remnant need not align with station XY. Free parts retain station quarter-turns and also try quarter-turns in the minimum-rotated-rectangle sheet frame. Grain locks retain the existing 0/180 station policy.

The actual-size three-copy case places one on Piece B and two on Piece A, with both programs verified. Additional angles increase work; no global optimum is claimed. Decision and evidence.

F01

Build a manufacturing workflow beyond a chat response

Connect physical indexing, persistent inventory, customer orders, nesting and verified output into one workflow.

The desktop now connects real SAM, pending review, accepted stock, prompt/DXF orders, batch selection, nesting and verified output. Factory process qualification remains outside the demonstrated scope.

F02

Borrow Recover-AI's hot-path / cold-path separation

Let AI perceive and interpret; keep repeated coordinate calculations, nesting, emission and verification in ordinary local code. The original proposal also placed AI-authored compiler preparation outside the numeric loop.

Numeric planning and verification run locally. Real Muse Code now prepares bounded GRBL and LinuxCNC emitters offline; validated emitters are reused without a coding-agent call for each job. SAM and order interpretation remain interactive cloud calls.

F03

Require meaningful AI integration and reject sponsor-driven additions

Use models where they perform necessary perception or language interpretation; judge additional services against the actual manufacturing workflow.

Real SAM, Muse Spark Open parsing and Muse Code-prepared controller emitters are implemented. The backend does not add sponsor services solely to create traffic; physical accuracy and process qualification remain unproven.

F04

Use a dedicated ArUco indexing station instead of loose A4 calibration

Fix four identifiable markers around a measured, flat station; place the remnant inside the visible markers.
